## ⚡ مميزات التطبيق (Features)

- 🚀 **واجهة سايبر حديثة وسريعة (Cyber Reactor UI)**: تصميم عصري وجذاب، فتح فوري للتطبيق واستجابة سلسة.
- 🎯 **تحديد الخادم بمرونة كاملة**: إمكانية اختيار الخادم والتبديل بين السيرفرات سواء أثناء الاتصال أو بدون اتصال.
- 📡 **مراقبة حية ودقيقة لنشاط الشبكة**: رسم بياني متدفق يعكس سرعات الرفع والتحميل الفعلية لحظة بلحظة.
- ⏱️ **قياس استجابة حقيقي (Real Server Ping)**: فحص ذكي ودقيق لزمن استجابة النفق الفعلي مع السيرفر دون أي قراءات وهمية.
- 🛡️ **دعم أوضاع الروت المتقدمة (ROOT Modes)**: دعم كامل لأوضاع `TPROXY` و `TUN` و `TUN2SOCKS` و `eBPF` لتوجيه حزم البيانات عبر طبقات النواة (Kernel-level).
- 📸 **التقاط الشاشة الافتراضي (Screenshots Allowed)**: مفعّل افتراضياً لسهولة مشاركة الإعدادات وحل المشاكل.
- 🔋 **استقرار واستهلاك منخفض للبطارية**: تم ضبط استهلاك الموارد والنظام لمنع استنزاف البطارية في الخلفية.
- 🌐 **دعم كامل للغة العربية والإنجليزية**: واجهة تدعم التوجيه السليم (RTL) مع إمكانية التبديل بين اللغات من الإعدادات.
- 🔒 **دعم شامل للبروتوكولات المشفرة**: VLESS, VMess, Trojan, ShadowTLS, Shadowsocks, WireGuard, Hysteria وغيرها.

## 🛠️ أنماط التشغيل (Run Modes)

### 1. وضع الـ VPN العادي (VPN Service - No Root)
- يعمل على جميع أجهزة أندرويد بدون الحاجة لصلاحيات الروت.
- يعتمد على معمارية `VpnService` الرسمية لنظام أندرويد بأعلى درجات التشفير والاستقرار.

### 2. أوضاع الروت المتقدمة (ROOT Modes)
- **TPROXY**: توجيه شفاف فائق السرعة عبر `iptables` و `Policy Routing`.
- **TUN / TUN2SOCKS**: إنشاء منفذ شبكة محلي وتوجيه الحزم بكفاءة عالية.
- **eBPF / BPF2SOCKS**: توجيه واعتراض الحزم عبر النواة مباشرة لأداء استثنائي للأجهزة الداعمة.

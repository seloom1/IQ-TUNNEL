# 🚀 تطبيق IQ TUNNEL - السورس كود النهائي المطور

هذا المجلد يحتوي على النسخة النهائية الكاملة لسورس كود تطبيق **IQ TUNNEL** بعد إنجاز كافة التعديلات، إصلاح المشاكل، وتحديث التصميم والبروتوكولات.

---

## 📌 معلومات الحزمة والهوية:
- **اسم التطبيق**: `IQ TUNNEL`
- **معرف الحزمة (Package Name)**: `com.iqtunnel.app`
- **الأيقونة الرسمية**: تم توليد ودمج هوية بصرية مخصصة مستوحاة من شبكات التونل والعراق.
- **إصدار أندرويد المستهدف**: `Target SDK 34` / `Min SDK 26` (Android 8.0+).

---

## ✨ أبرز التعديلات والإصلاحات البرمجية المنجزة:

### 1. ⚡ إصلاح ودعم استيراد بروتوكول WireGuard بالكامل:
- **المعالجة الثنائية (قائمة الخوادم + نقاط الانتهاء)**:
  - أصبح التطبيق يدعم استيراد روابط `wireguard://`, `wg://`, `warp://`, `awg://` مباشرة من **قائمة الخوادم (Servers List)** وكذلك من **نقاط الانتهاء (Endpoints)** بدون أي أخطاء `Invalid Configuration`.
- **حل مشكلة مفاتيح Base64 المشفرة**:
  - تم إصلاح فك الترميز بحيث لا تتحول إشارة الزائد `+` إلى مسافة، مع ضبط الحشو (`padding`) تلقائياً.
- **التوافق التام مع نواة sing-box الحديثة**:
  - في `SingBoxConfigCompiler.kt`: تم ضبط النواة لتجميع عقد `WireGuard` ضمن مصفوفة `endpoints: [...]` القياسية لمنع أخطاء التقادم، مع إدراج العقدة في مجموعات الخوادم والـ `Global Selector` ليتمكن المستخدم من اختيارها، فحص سرعتها (`Ping`)، والاتصال بها مباشرة.

### 2. 🛡️ استقرار التشغيل المستمر في الخلفية (Background Running):
- تم إضافة أذونات اليقظة واستثناء البطارية في `AndroidManifest.xml`:
  - `WAKE_LOCK`
  - `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`
  - `POST_NOTIFICATIONS`
- تعديل خدمة `AsteriskVpnService` لتعمل بوضع `START_STICKY` مع `Partial WakeLock` لحماية الاتصال من الإغلاق عند الخروج من التطبيق.
- طلب أذونات الإشعارات واستثناء البطارية تلقائياً عند فتح التطبيق لأول مرة.
- تفعيل إشعار إحصائيات حركة البيانات في الخلفية افتراضياً.

### 3. 🎨 الواجهة ومؤشرات الشبكة والبنك (Ping):
- قياس سرعة الاستجابة (`Ping`) الفعلي من خلال فحص عنوان الخادم المباشر مع استخراج عنوان السيرفر والمنفذ لعقد `WireGuard` تلقائياً.
- ضبط مؤشرات حركة الشبكة (الرفع والتنزيل) مع عرض حالة الاتصال والبروتوكول (`WG`, `VLESS`, `VMess`, إلخ).
- زر التوجيه إلى قناة التليجرام عند الاتصال بالسيرفر.

## 📁 هيكلية المجلدات الرئيسية:
```text
IQ_TUNNEL_FINAL_SOURCE/
├── app/                                 # كود تطبيق الأندرويد والواجهات
│   └── src/main/
│       ├── kotlin/
│       │   ├── app/                     # نقطة البداية، إدارة الحالة، MainActivity
│       │   ├── engine/                  # النواة، المترجم (SingBoxConfigCompiler)
│       │   ├── features/                # الخوادم (outbound)، الواجهات، الإعدادات
│       │   └── ui/                      # واجهات Jetpack Compose
│       └── res/                         # الموارد، الأيقونات والقيم
├── asteriskd/                           # خدمة الخلفية للنواة
├── bpf2socks/                           # طبقة دعم eBPF للشبكة
├── bpfmatcher/                          # محرك مطابقة حزم BPF
├── enhance/                             # تحسينات التوجيه
├── hevtun/                              # محول التونل HevSocks5Tunnel
├── apk_builds/                          # نسخ APK الجاهزة للتثبيت المباشر
│   ├── IQ_TUNNEL_arm64_v8a.apk          # لأجهزة أندرويد الحديثة (64-bit)
│   └── IQ_TUNNEL_universal.apk          # نسخة شاملة لجميع الأجهزة
├── build.gradle.kts                     # إعدادات البناء العامة
└── README_FINAL.md                      # هذا الملف
```

## 🛠️ طريقة بناء التطبيق من السورس كود:
افتح سطر الأوامر (Terminal أو PowerShell) داخل هذا المجلد وشغل الأمر:
```powershell
$env:JAVA_HOME="مسار_JDK_17"
.\gradlew assembleDebug
```
ستجد ملفات الـ `APK` الناتجة في مسار:
`app/build/outputs/apk/debug/`
